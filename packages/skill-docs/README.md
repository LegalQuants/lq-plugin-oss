# Skill design notes

These public design notes explain the intent, workflow, boundaries, and known limitations of selected skills in the current bundles. The authored runtime source remains the matching `skills/<group>/<name>/SKILL.md`.

The notes are contributor documentation and are not copied into generated plugins. Public tests and synthetic fixtures live under `packages/skill-tests/` and the owning package. Private evaluation campaigns, confidential corpora, historical review records, and results remain outside this repository.

Some shipped skills do not yet have a public design note. That is an incomplete documentation surface, not a claim that the skill lacks an owner or validation.
