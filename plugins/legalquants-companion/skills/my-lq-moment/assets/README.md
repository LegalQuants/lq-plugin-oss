# Cover template

`cover-template.png` (1200 × 1200) is the foundation for every "My LQ Moment"
cover; see `../references/cover.md` for how text is set on it. It is
supplied by the maintainer, not generated, and is never altered, cropped,
recoloured or obscured. If the file is missing, the skill cannot produce a
cover: say so and give the approved text. Practice covers use the same fixed
template through `render_cover.py --practice`, which permanently adds the
required fictional-training label.
